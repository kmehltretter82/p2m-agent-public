# M6 and M7 results

## M6: a private reduction, live (1 November 2026)

Hand-written toys through the real gate, `submit()` and `sync_obligations()`, with no model. The toys
are deprecated, and `make-public` was never called.

| Stage | Server | Ledger |
|---|---|---|
| Reduction submitted, child open | `SKETCH_ACCEPTED`, parent `Open` | `reduction_open`, counted as 0 proved |
| Child proved | child `ACCEPTED`, parent `Proved` | `proved_via_reduction`, obligation `Proved` |

The parent's own submission flips from `SKETCH_ACCEPTED` to `ACCEPTED` on the server, so polling
it is enough. The gate reported `sorryAx`, which is expected through a mirrored import.

**Side effect:** closing the two toys added 2 to `num_solved_prob`, `trust` and `num_submitted_prob`.

## M7: the Pi 500+ (2 November 2026)

- **Service:** `deploy/pi/p2m-agent@.service`, installed with the user's approval, runs the agent side
  of the benchmark as the `prover` account. Nothing it runs is submitted. It was enabled at boot for
  this test, and the user has since stopped and disabled it.
- **Restart:** a reboot in the middle of a proof brought the Pi back in under a minute, the service
  started by itself, and the interrupted attempt resumed its session and finished `proved_locally`.
  This was a clean reboot, not a power cut, which remains untested.
- **Thermals:** 8 minutes of Lean compiling on all four cores (peak load 11.85) peaked at 53.2C, held
  2.4 GHz, and showed `throttled=0x0` in all 33 samples. The temperature was still at its peak when the
  test ended, so this shows no throttling over 8 minutes, not over a day.
- **State transfer:** `p2m export` and `p2m import` moved the real ledger of 10 attempts to a fresh
  directory, and the report matched.
- **Local Loogle works here.** The binary built in 22s and the first Mathlib index took about 4 minutes,
  peaking at 13.9 GB resident with 8.68 GB still available. A warm start takes 7s and holds 7.7 GB
  resident. Queries returned in 0.2s to 0.8s. The worker does not use it yet: that is an M8 upgrade.
- **Still open:** the 24-hour run and a real power cut. The agent proved all 5 known-proved targets it
  finished before the service was stopped, a smaller check than M7 asks for.

Token counts undercount interrupted attempts, because usage is only reported when a query ends.
